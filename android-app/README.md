# FTS Printer Samsung / Android

Interne installierbare Test-App für Samsung / Android.

## v0.1.0 TEST
- Einmalige Gerätefreigabe per FTS Admin-Code
- Mitarbeiter-/Printer-Admin-Login mit persönlichem Code
- Aktuelle Printer-Events
- Selfie-Druckaufträge + Abholcodes
- Zwei-Schritt-Druck: Druckdialog öffnen, danach Erfolg bestätigen
- Kundenbeleg anzeigen und drucken
- Materialbestand ansehen
- Bestandsänderung nur nach erneuter Eingabe des persönlichen Codes
- Kamera-/Handyfoto lokal auswählen und über Android Print Service drucken
- Kamera-Print getrennt als Materialverbrauch buchen
- Keine Firmenbuchhaltung und keine Gesamtumsätze in der App

Die Test-APK ist mit der Android-Debugsignatur gebaut. Für die spätere Produktionsversion wird eine dauerhafte private FTS-Signatur eingerichtet.
