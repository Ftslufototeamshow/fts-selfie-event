# FTS Printer macOS

Native macOS Printer-App für FTS Selfie Event.

## Version 0.1.0
- Einmalige Gerätefreigabe mit FTS Admin-Code.
- Mitarbeiter-/Printer-Admin-Login mit persönlichem Code.
- Keine Firmen-Umsatzübersicht in der App.
- Aktuelle Printer-Events und Selfie-Druckaufträge.
- 10×15-Druck über den macOS-Druckdialog.
- Kundenbeleg pro Auftrag.
- Materialbestand und geschützte Bestandsänderungen.
- Lokaler Eventordner wird erst nach manueller Freigabe erstellt.
- Automatische Überwachung eingelegter Speicherkarten.
- Nur neue Dateien ab Event-Freigabe.
- SHA-256 verhindert doppelte Importe auch bei anderen Dateinamen.
- Karten-/Kamera-Kennung wird soweit verfügbar protokolliert.
- Kamerafotos bleiben lokal und werden nicht in den Selfie-Storage hochgeladen.

Die App wird als Universal Binary für Apple Silicon und Intel gebaut.
